使用帮助

快速上手

  1. 导入素材 — 支持 MP4 / MOV / WebM / MKV 视频、常见图片、MP3 / WAV / M4A 音频与 TXT 文本。
  2. 编排轨道 — 点击素材「+」加入时间轴，拖动片段移动，拖动两端进行裁剪。
  3. 叠加内容 — 文本、图片、字幕拥有独立的入场 / 出场动画与样式设置；字幕支持滚动上移、静态多行与跑马灯三种呈现方式，滚动类字幕可调滚动速度。
  4. 录像 — 点击右上角「录像」，最长可录制 1 小时；按 Esc 结束，录像会自动导入视频轨。网页版共享时勾选「分享音频」即可录到窗口声音；打包版请选择「立体声混音」或虚拟声卡作为声音来源。
  5. 扩展屏播放 — 点击「扩展屏」即在副屏播放，再次点击停止，再点击继续播放；主屏可继续编辑，修改实时同步。
  6. 导出 — 右上角「导出视频」，自动优先输出 MP4，否则回退 WebM。
  7. 文字配音 — 左侧切到「文字配音」，输入文本、选择普通话朗读者，生成的语音会加入配音轨，可单独裁剪与调节音量（离线合成，需在桌面版中使用）。
